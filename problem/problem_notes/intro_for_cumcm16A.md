# 四、题目真正要求你们输出什么

## 1\. 钢桶和各节钢管的倾斜角度

题目明确规定：

> 钢桶倾斜角是钢桶轴线与竖直线之间的夹角。

钢管的倾斜角题面没有单独定义，通常也应以竖直方向为基准，但你们必须在论文中明确写出自己的角度约定。

尤其要提前规定钢管编号，例如：

```
从浮标向下依次编号为第1、2、3、4节
```

或者：

```
从钢桶向上依次编号为第1、2、3、4节
```

题面只说钢桶“上接第4节钢管”，但图中没有完整标注编号。论文中如果不先定义，后面的“第1节倾角”和“第4节倾角”容易前后颠倒。

此外，题目要求的是**每一节钢管的倾角**，不能未经说明就把四节钢管当成一根完全笔直的杆，只报告一个总倾角。

* * *

## 2\. 锚链形状

“锚链形状”不能只给一个“倾斜角”或一张没有坐标的曲线图。

至少要能说明：

-   锚链是否有一部分平铺在海床上；
-   哪一部分悬空；
-   锚链从哪里离开海床；
-   悬空部分的空间位置；
-   锚端和钢桶端附近的切线方向；
-   不同环境条件下形状如何变化。

一个关键事实是：

> 锚链不一定整条悬空。

当锚链部分落在海床上时，系统状态和整条链全部拉离海床时有明显区别。这个状态转换是本题的重要物理现象，不能始终默认锚链是一条悬空曲线。

* * *

## 3\. 浮标吃水深度

吃水深度是：

> 海面到浮标底部的竖直距离，也就是浮标浸入水中的高度。

它不是：

-   海水总深度；
-   浮标中心到海面的距离；
-   浮标顶部露出海面的高度；
-   钢管上端所在深度。

吃水深度同时参与两个方面：

1.  决定浮标排开多少海水；
2.  决定浮标有多少面积暴露在空气中、多少面积浸在水中。

因此，吃水深度不是最后单独附加计算的量，而是和整个系统状态相互关联的量。

* * *

## 4\. 浮标游动区域

“游动区域”是本题一个没有完全明确定义的词。

你们需要在论文中明确回答：

-   是指浮标中心的水平位移吗？
-   是指相对锚点的最大水平距离吗？
-   报告的是游动半径、直径还是面积？
-   风向固定时是一条方向上的位移，还是考虑风向变化后的平面区域？
-   浮标自身半径是否计入覆盖区域？

较稳妥的表达方式是先定义一个明确的参考点，例如浮标轴线中心，然后分别报告：

-   相对锚点的水平偏移；
-   风向任意变化时对应的游动半径；
-   必要时再给出游动直径或覆盖面积。

最忌讳的是全文只写“游动区域为某某米”。“区域”通常不能直接以米为单位，除非你们明确说这个数是半径或直径。

* * *

## 5\. 锚端安全角

题目要求：

> 锚链末端与锚连接处的切线方向，与海床的夹角不得超过16°。

注意这里是：

-   锚端；
-   锚链切线；
-   相对海床；
-   不超过16°。

不能误写成：

-   钢桶端锚链角度；
-   锚链整体平均倾角；
-   锚链与竖直方向夹角；
-   钢桶倾角。

如果锚附近仍有锚链平铺在海床上，则锚端局部方向与整条悬空部分的方向也不是一回事。

# 五、问题1到底在考什么

问题1给定：

-   II型锚链；
-   总长22.05 m；
-   重物球质量1200 kg；
-   水深18 m；
-   海水密度；
-   无水流；
-   风速分别为12 m/s和24 m/s。

要求计算两种风速下的完整系统状态。

## 这是一道“已知配置的性能检验”

问题1不是让你们选择锚链，也不是让你们调整重物球。

设计参数已经固定，你们需要回答：

> 在两个不同风速下，这套已有设备实际会变成什么样。

两种风速是两个独立工况，不能只算一次后按比例放大所有结果。虽然题目给出的风荷载随风速平方变化，但倾角、吃水深度、锚链接触状态和游动范围之间存在相互影响，最终状态通常不会简单按同一个比例变化。

## “海水静止”的准确含义

它表示：

-   海水流速为零；
-   不考虑水流产生的水平荷载。

但仍然存在：

-   海水浮力；
-   各构件重力；
-   风对浮标露出水面部分的作用；
-   构件之间的拉力和作用力。

“海水静止”绝不等于“整个系统没有受力”。

## 问题1的完整结果应当分工况报告

建议至少形成这样的结果结构：

| 钢桶倾角 |     |     |
| 第1节钢管倾角 |     |     |
| 第2节钢管倾角 |     |     |
| 第3节钢管倾角 |     |     |
| 第4节钢管倾角 |     |     |
| 浮标吃水深度 |     |     |
| 浮标水平偏移 |     |     |
| 锚链海床接触情况 |     |     |
| 锚端角度 |     |     |
| 锚链形状图 |     |     |

即使问题1没有直接要求检查16°和5°，也建议顺便报告，因为它们是判断该配置是否合理的重要指标。

# 六、问题2最容易漏掉的“两阶段任务”

问题2仍沿用问题1的基本环境和原有配置，只把风速提高到36 m/s。随后要求调整重物球，使：

-   钢桶倾角不超过5°；
-   锚端锚链角不超过16°。

## 第一阶段：先检查原有1200 kg重物球

题目先说：

> 计算36 m/s时的系统状态。

因此不能一上来就改变重物球质量。

应该先回答：

> 原来的II型、22.05 m锚链和1200 kg重物球，在36 m/s下表现如何。

这是“原方案检验”。

## 第二阶段：再调节重物球质量

然后才是：

> 改变重物球质量，使两个明确约束同时满足。

这是“方案调整”。

很多队伍会直接寻找一个满足5°和16°的质量，却没有给出原始1200 kg方案在36 m/s下的情况，这会漏掉题目前半问。

## 不能只看钢桶的5°

增加重物球质量后，改变的不只是钢桶倾角，还可能影响：

-   浮标吃水；
-   各节钢管倾角；
-   锚链悬空长度；
-   锚链是否接触海床；
-   锚端角度；
-   浮标游动范围。

所以调节后必须重新检查整个系统，不能只重新计算钢桶一个角度。

## “调节质量”不等于无限增大质量

题面没有直接说“求最小质量”，但显然不能通过使用一个极端大的重物球草率满足倾角条件。

至少需要说明你们采用了什么选择原则，例如：

-   满足全部硬约束；
-   浮标仍能保持合理浮态；
-   尽量避免无意义的过大配重；
-   系统各项指标均可接受。

这里的选择标准必须由你们明确写出，不能只给一个质量数字而不解释为何选它。

# 七、问题3是整道题真正的“设计题”

问题3的环境不再固定：

-   水深在16～20 m之间变化；
-   水流速度最大1.5 m/s；
-   风速最大36 m/s。

而且要求你们自行确定：

-   锚链型号；
-   锚链长度；
-   重物球质量。

并分析不同情况下的钢桶姿态、钢管姿态、锚链形状、浮标吃水和游动区域。

## 1\. 不能只计算一个所谓“最危险工况”

“不同情况下”意味着需要覆盖一个环境范围。

只计算：

```
水深20 m、风速36 m/s、流速1.5 m/s
```

然后就结束，并不充分。

原因是不同指标的最不利环境未必完全相同。例如：

-   更深的水不一定对所有指标都更不利；
-   较浅水深可能增加锚链在海床上的余量；
-   较深水深可能使锚链更容易被拉起；
-   最大水平荷载可能控制倾角；
-   另一些组合可能控制吃水或游动范围。

因此必须有明确的工况覆盖方案，而不是凭直觉选一个组合。

## 2\. 风向和水流方向没有给出

题目只给了风速和水流速度，没有说明：

-   风和水流是否同向；
-   是否反向；
-   是否相互垂直；
-   方向是否随时间改变。

这是问题3必须主动处理的题意空缺。

你们需要明确声明自己的处理方式，并解释为什么这样处理。不能在计算过程中默认同向，论文里却完全不写。

## 3\. 水流是否随深度变化也没有说明

题目只说“海水速度最大可达到1.5 m/s”，没有给出垂向流速分布。

因此你们不能声称题面明确给出了均匀流，也不能自行虚构复杂的海流剖面。采用任何简化，都应标记为你们的假设，并在结果分析中说明该假设可能造成的影响。

## 4\. 问题3不是只追求角度最小

题目说浮标吃水深度、游动区域和钢桶倾角“尽可能小”，但这几个目标之间可能发生冲突：

-   更重的配重可能改善姿态，却增加浮标负担；
-   更长或更重的锚链可能改善锚端状态，却扩大系统占用范围；
-   更短的锚链可能限制游动，却更容易拉高锚端角度。

因此，最终设计必须说明：

> 为什么这套方案整体上更合理，而不是某一个指标单独最好。

# 八、题目中没有完全给出的数据

这是A题中很重要的判断能力：**不要假装所有数据都齐全。**

## 1\. 重物球只有质量，没有尺寸和材质

题面没有给出：

-   重物球直径；
-   体积；
-   密度；
-   是否实心；
-   材料。

因此它在水中的浮力无法由题面唯一确定。

你们后续必须对这一点作明确处理，不能一边计算重物球水下受力，一边假装题面已经给出了球体体积。

## 2\. 锚链没有给出完整截面几何

附表只有：

-   单个链环长度；
-   单位长度质量。

没有给出：

-   链环钢材直径；
-   排水体积；
-   材料密度；
-   链环宽度。

所以锚链水下浮力同样存在数据缺口。

## 3\. 锚的抗拖移信息不完整

虽然锚的质量为600 kg，但题面没有给出：

-   海床摩擦系数；
-   锚的抓地力；
-   土壤类型；
-   极限抗拔或抗滑能力。

题目已经直接给出了“锚端角度不超过16°”这一安全判据，因此不要擅自编造海床摩擦参数，再宣称完成了精确的锚滑移计算。

## 4\. 重力加速度没有指定

使用什么取值需要统一说明。不同队员不能一部分使用一种数值，另一部分使用另一种数值。

## 5\. 连接节点形式没有详细说明

题面没有明确钢管之间的连接是：

-   完全刚接；
-   完全铰接；
-   具有一定转动刚度。

图中各节钢管并不完全共线，题目又要求分别计算各节倾角，因此你们必须对节点的受力和转动特性作一致约定。

# 九、投影面积是一个隐藏的高频错误点

题目给出的风力和水流力都依赖法向投影面积 (S)。

但 (S) 不是永远固定的。

## 对浮标

风只作用于露出海面的部分，因此浮标吃水变化后：

-   露出高度变化；
-   迎风投影面积变化；
-   风力也随之变化。

水流作用于浸没部分，因此水下投影面积也与吃水有关。

## 对钢桶和钢管

它们是倾斜的细长构件，面对水平水流时的投影面积会随姿态变化。

因此不能无条件把：

```
长度 × 直径
```

作为所有倾角下完全相同的水流投影面积。

## 对重物球

球体方向不影响正投影面积，但题面没有给出其半径，所以又回到了数据缺失问题。

## 读图错误

-   把重物球串联进主链路；
-   把钢管节点当作重物球；
-   从示意图读取钢桶实际倾角；
-   把18 m尺寸虚线当作构件。

## 物理量错误

-   把质量直接当成力；
-   对所有水下构件只算重力、不考虑浮力；
-   用浮标全部高度计算迎风面积；
-   混淆吃水深度和水深；
-   把钢桶5°与锚链16°混为同一个约束。

## 锚链错误

-   默认整条锚链始终悬空；
-   默认整条锚链始终铺在海床；
-   只给曲线图，不说明海床接触段；
-   报告钢桶端角度，却说是锚端角度；
-   把表中105 mm误认为II型锚链总长度。

## 问题结构错误

-   问题1擅自调整设计参数；
-   问题2跳过原1200 kg方案，直接改变重物球；
-   问题2只验证钢桶5°，不再检查锚端16°；
-   问题3只计算最大风、最大流、最大水深一个组合；
-   问题3给出设计参数，却没有展示不同环境下的表现。

## 论文表达错误

-   不定义角度方向；
-   不定义钢管编号；
-   “游动区域为20 m”但不说是半径还是直径；
-   假设散落在计算过程中，没有统一列出；
-   使用题目未提供的数据，却写成“根据题意可知”。
