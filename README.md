# CUMCM 2016 A 题建模项目

本仓库用于管理题目材料、经确认的模型说明、可复现代码、运行产物和论文源文件。当前仅完成项目初始化；尚未开始题目分析、建模或计算。

## 目录约定

- `problem/original_problem/`：原始题目、附表和题图；`problem/problem_notes/`：题目阅读与口径记录。
- `data/raw/`：只读原始数据；`data/processed/`：代码生成的处理后数据。
- `model_cards/`：各子问题经团队确认后的模型交接单。
- `src/q1/`、`src/q2/`、`src/q3/`：各子问题代码；`src/common/`：共享代码。
- `outputs/q*/`：程序运行生成的 `figures/`、`tables/` 和 `logs/`。
- `docs/`：结果总账、待确认事项与模型说明。
- `paper/`：论文 LaTeX 源文件、章节、图和表。

## 工作顺序

1. 先将已确认的输入、输出、变量、假设、公式、参数、图表和验证方式写入对应模型卡。
2. 再实现可复现的最小代码版本，并将产物写入 `outputs/`。
3. 将经验证的结果登记到结果总账后，才可写入论文。
