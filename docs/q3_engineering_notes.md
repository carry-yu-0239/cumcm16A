# 问题三工程原型说明（暂不写论文）

本文件记录 `src/q3/q3_engineering.py` 的工程口径。当前内容**未写入** `model_cards/q3.md`，也**未修改** `paper/sections/08_problem3.tex`。

## 已锁定内容

- 对外符号沿用 `paper/sections/04_symbols.tex`：钢管倾角 `theta_i`、钢桶倾角 `theta_d`、锚端夹角 `varphi_a`、吃水深度 `delta`、游动半径 `r`。
- 吃水深度 `delta` 为内层自变量，计算模型水深 `H(delta)`；求指定水深时，用一维根求解满足 `H(delta)=H_target`。
- 水流荷载采用题面近似式 `F=374 S v_c^2`，风荷载沿用前两问。
- 钢管、钢桶、锚链均采用建模手本轮给出的逐段力平衡与力矩平衡思路。
- `v_c=0` 时必须退化到问题二既有静水模型。

## 工程实现中的未确认闭合

这些内容用于让程序先跑通和进行参数扫描，**不视为团队已确认的模型事实**：

1. 手稿中单独写出的 `tan(phi_i)` 与两条力矩方程、以及论文中“钢管倾角为与竖直方向夹角”的定义存在倒数关系；程序以两条力矩方程为控制式，不直接采用该孤立 `tan` 公式。
2. 钢桶/重物球部分有一行水平、竖直分量符号重复。程序内部使用水平/竖直张力分量避免角度符号混用：水平分量累加水流力，竖直分量扣除钢桶和重物球水中有效重力。
3. 浮标水流力严格按建模手手稿 `F_cb=374*delta*v_c^2` 实现，不额外乘浮标直径。
4. 手稿给出重物球水流力 `F_cs`，但未给投影面积；工程原型按钢球质量和钢密度求球半径，再取球体法向投影面积 `pi*r_s^2`。
5. “锚链段分析同上”需要链条受流投影尺度，但题面只给单位长度质量和链环长度；工程原型暂由单位长度钢质量除以钢密度得到等效截面积，再换算等面积圆杆直径。该口径必须由建模手确认后，才能进入正式 Q3 模型卡和论文。

## 回归核验

工程原型在 `H=18 m`、II 型 210 节、`m_s=2250 kg`、`v_w=36 m/s`、`v_c=0` 下回归问题二，得到：

- `theta_d = 4.4251401217 deg`
- `varphi_a = 15.8259582197 deg`
- `delta = 0.9928460903 m`
- `r = 18.5314796804 m`

与仓库既有 Q2 结果的最大绝对误差约为 `3.2e-14`。

## 当前工程基准

为生成参数关系表和 16/20 m 锚链形状图，当前仅采用一个**工程基准**：II 型 210 节（22.05 m）、`m_s=2250 kg`、`v_w=36 m/s`、`v_c=1.5 m/s`。该基准不是问题三最终设计结论。

在这一基准下，16 m 与 20 m 两端工况均不能同时满足 `theta_d<=5 deg` 和 `varphi_a<=16 deg`，因此后续正式 Q3 仍需在锚链型号、长度和重物球质量上继续设计搜索。
